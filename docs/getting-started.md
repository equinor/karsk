# Getting started

## Requirements

- **Python 3.11** or newer.
- A container engine like [Podman](https://podman.io/) or
  [Docker](https://docker.com). We primarily use the former in production, but
  the latter is also supported.
- `rsync` and passwordless SSH access to the target hosts.

## Installing

Karsk is available on [PyPI](https://pypi.org/project/karsk)

```sh
pip install karsk
```
